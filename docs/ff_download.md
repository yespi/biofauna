# Dataset photos via FotoFauna (BioFauna Fotos)

This public repo **does not ship photographs** (licence + size). Admins of
[FotoFauna](https://fotofauna.yespi.es) can export the live gallery from the
**BioFauna Fotos** panel: ZIP parts ≤ 2 GB, CSV per species folder, optional
taxonomic folder tree or flat layout, merge via `DOBLE_CLIC_Unir_CSVs.bat`.
See [yespi/fotofauna `docs/BIOFAUNA_FOTOS.md`](https://github.com/yespi/fotofauna/blob/master/docs/BIOFAUNA_FOTOS.md).

Catalog size and OOS accuracy: [`STATUS.md`](STATUS.md). Photo copyright stays
with observers and the source platforms (Minka, iNaturalist, GBIF, …).
